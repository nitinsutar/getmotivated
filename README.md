Minimal hard-hitting motivational quotes.

One quote at a time. Full screen. No distractions.

## Features (v1)

- Massive bold typography
- Dark, calm background
- Click / Space / Swipe for next quote
- "Next" indicator fades out after a few seconds
- Vercel Web Analytics integration for privacy-friendly visitor insights

Built to feel like a quiet room.

## Analytics Setup

This project includes Vercel Web Analytics for tracking visitor data in a privacy-friendly way.

**To enable analytics:**
1. Go to your [Vercel Dashboard](https://vercel.com/dashboard)
2. Select this project
3. Navigate to the "Analytics" tab
4. Click "Enable Web Analytics"
5. Deploy the project (or wait for the next deployment)

Once enabled, analytics data will automatically start being collected without requiring any additional configuration.
